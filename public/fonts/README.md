# DotGothic16

Source: Google Fonts `ofl/dotgothic16` distribution:
https://github.com/google/fonts/tree/main/ofl/dotgothic16

Copyright 2020 The DotGothic16 Project Authors.
Redistributed under the SIL Open Font License 1.1 in `OFL-DotGothic16.txt`.

`DotGothic16-Regular.woff2` is an offline WOFF2 format conversion using
FontTools 4.57.0. No subsetting or glyph modification was performed. All 9,362
glyph drawing commands, character mapping, horizontal/vertical metrics and
font naming/layout tables were verified equal to the source TTF. The font's
internal copyright/license metadata is retained.

Source TTF SHA-256: `3ad9af88726d42b40f7f365f0dcac785af73cf20ea6f1d5b44e57cc21150b8f1`.

Used only by the explicitly selected dot appearance. The optional stylesheet
is loaded on demand. There is no preload or startup font-readiness gate.
A failed font download falls back to system fonts.
