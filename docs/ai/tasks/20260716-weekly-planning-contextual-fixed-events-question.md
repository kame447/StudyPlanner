# 登録済み予定を根拠に固定予定を確認する

Status: closed
Closed: 2026-07-16
Parent: `20260716-weekly-planning-conversation-hardening.md`

## 対象問題

固定予定の質問が登録済み予定を参照せず、一律に「授業・バイト・通院など、動かせない予定があれば教えてください」と尋ねる。

これは既知情報を再質問するうえ、例示が特定の生活事情に寄っている。利用可能な予定がある場合は、確認できた予定を示したうえで追加分だけを尋ねるべきである。

## 方針

pipeline inputの`existingPlans`から計画期間内の予定を抽出し、ユーザー向けの短いsummaryへ変換する。rendererへ明示的な既知予定summaryを渡し、fixed events質問だけがそれを利用する。

予定が存在しない場合は「すでに登録した予定以外に、時間が決まっていて動かせない予定はありますか？」のような一般表現を用いる。病院・通院など個別事情に寄った固定例は初期質問から除く。

予定名や時刻は既存データからのみ生成し、AIによる補完や捏造を許可しない。

## 完了条件

- [x] 計画期間内の登録済み予定だけをsummaryへ含める
- [x] 既知予定がある場合は代表例を示して追加予定を尋ねる
- [x] 既知予定がない場合は一般表現で尋ねる
- [x] 予定名・日付・時刻を入力データ外から生成しない
- [x] deterministic rendererとAI rendererの双方へ同じgroundingを渡す
- [x] 固定予定の説明・回答例から個人事情に寄った語を除く
- [x] 回帰テストを追加する
