## Decision and next action

Use a private Cloudflare R2 binding on the existing Worker. Firestore keeps an immutable receipt containing at most three image descriptors (digest, byte length, image type and dimensions), never image bytes or public download URLs. Only an accepted receipt grants fixed upload slots. The original 60-second receipt transaction remains authoritative, including retries. Authenticate every upload/read using Firebase; uploads require the receipt owner and downloads require a currently enabled administrator. No service-account privilege expansion is needed: receipt/admin reads use the caller's Firebase token and Firestore Rules.

Firebase Storage would require a second storage authorization/rules/deployment surface. Inline Firestore bytes would increase reads/document sizes. R2 behind the existing Worker gives the smallest isolated object-storage boundary; this choice would need revisiting if deployment cannot provide a private R2 binding or existing Firebase project configuration.
