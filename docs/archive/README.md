# Documentation archive

Everything under this directory is historical evidence, not current implementation instruction.

- `audits/`: review/adversarial evidence
- `work/closed/`: completed task records
- `work/superseded/`: replaced task records
- `weekly-planning/`: old weekly-planning architecture/status/debug/design records
- `engineering/`: historical repository-wide engineering/refactor records

Historical files may contain old branch names, PR numbers, `Status: active`, old paths or contracts that were valid only at the time. Do not resume work from them without checking the current domain README, current code and current Issue.

Old relative links inside archived evidence may refer to the pre-2026-08-22 layout; use `docs/DOCUMENT_DICTIONARY.md` migration map or Git history when tracing provenance.
